# Soft Moon Studio Pinterest Pins

Use this workflow for blog-assisted Pinterest affiliate campaigns.

## Funnel

Send each Pin to a useful Soft Moon Studio article. Do not link these campaign Pins directly to Amazon.

Use:

```text
Pinterest Pin -> Soft Moon Studio guide -> disclosed Amazon affiliate cards
```

Add a unique `utm_content` value to every Pin URL.

## Visual System

- Create vertical `1000 x 1500` PNG assets.
- Keep one clear mobile-readable promise per Pin.
- Prefer `4-10` headline words. Use a short second line only when needed.
- Use warm editorial lifestyle imagery that matches the landing page.
- Use cream, taupe, warm brown, muted blush, and charcoal.
- Use an editorial serif headline with a restrained sans-serif kicker and brand line.
- Keep `Soft Moon Studio` subtle but visible.
- Create genuinely different compositions and angles. Do not generate cosmetic duplicates.
- Do not imply that a contextual lifestyle photo shows the exact Amazon product.
- Do not download or re-upload Amazon product images for Pin creative.

## Campaign Pattern

For one useful evergreen guide:

1. Create `8-10` initial Pins across multiple search and decision angles.
2. Schedule `2` Pins per week for `4-5` weeks.
3. Keep `2` reserve Pins for later testing.
4. Save each unique Pin once to the most relevant board first.
5. Use a broader related board only for selected later variants.
6. Review outbound clicks after at least `21-30` days before producing more variants.

## Required Metadata

For each Pin record:

- asset filename
- publish date
- board
- Pin angle
- title
- description
- destination URL with UTM parameters
- status

Descriptions should be useful and natural. Include:

```text
This post contains affiliate links.
```

## Review Checklist

- Pin promise matches the landing page.
- Headline is readable at mobile thumbnail size.
- Image and copy reflect the same room, mood, or problem.
- Asset is `1000 x 1500`.
- Pin has a unique UTM URL.
- Pin is assigned to one primary board.
- No unsupported health, urgency, or product-performance claims.
- Commercial context is disclosed in the description.
